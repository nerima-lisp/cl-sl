# Roadmap

v0.1.0 covers the classic `sl` behaviors: the default run, `-a`/`--accident`,
`-l`/`--little`, `-F`/`--fly`, `--fps`, `--help`/`--version`, and an early-quit
`q` key for consistency with the org's other real-time terminal programs.

Nothing further is currently planned; issues are welcome at
<https://github.com/nerima-lisp/cl-sl/issues>.
