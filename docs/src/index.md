# cl-sl

An original reimplementation of the classic Unix joke command `sl` (Steam
Locomotive): mistype `ls` as `sl` and, instead of a shell error, an original
hand-authored steam locomotive runs across the terminal and exits
automatically once it scrolls off screen.

Every sprite -- the locomotive, its cargo/log cars, the wings of the `-F`
variant, and the `-a` accident sprite -- is original art authored for this
repository. None of it is copied or transcribed from the classic `sl.c`
train art.

See [Getting started](getting-started.md) to run it, or the
[API reference](reference/api.md) to use it as a library.
